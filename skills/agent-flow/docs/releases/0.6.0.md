# Agent Flow 0.6.0

Document status: done

This release removes everything that does not serve the core goal — guiding
code from PRD to verified production delivery — and makes the remaining
tooling self-maintaining. About 30% of the codebase is gone with no loss of
acceptance behavior.

- **Removed: the model evaluation platform.** The frozen model-eval harness
  (ten modules, ten test suites, its testdata, and the CI machinery that
  existed only for it — Go/Bun/browser/Codex pins and sandbox tool roots) is
  deleted. Model selection concluded long ago; git history preserves the code.
  The Harness Evaluation learning gate and evidence promotion stay in the core.
- **Removed: codegraph.** Procedures referenced it only as optional guidance;
  no gate depends on it. The tree-sitter requirements and preflight go with it.
- **Removed: the root shim layer.** Thirty-eight runpy proxies are gone; CI and
  developer docs call package scripts by their real paths.
- **The test suite is discovered, not registered.** `check-all.py` finds
  `test-*.py` by traversal, so forgetting to register a test is impossible.
- **The package inventory is generated, not listed.** The 1466-line
  `package-files.txt` manifest is replaced by a deterministic walk of the
  allowlisted package directories. Distribution archives are runtime-only
  (no golden traces, no tests): the plugin ZIP shrinks from 5.3 MB to 2.0 MB.
- **One artifact, self-verifying build.** Only the Codex plugin ZIP is built
  and published; `npx skills add` installs straight from the repository. The
  build re-reads and verifies the archive it just wrote; the separate verifier,
  the skill ZIP, per-file hash records, development builds, and the
  replace-published-release machinery are removed.
- **Minimal CI.** A single ubuntu job runs the full suite; tags build and
  publish through the preinstalled GitHub CLI. The workflow is 85 lines instead
  of 261, with no browser/Go/Bun/gh pinning.
- **Role config has one source.** Role frontmatter stays the only machine
  source; the resolver runs as `agent_config.py --role`, the role catalog
  validates name coverage only, and README role counting is gone.

Breaking for development workflows only: helper scripts and development
commands listed above no longer exist. Acceptance behavior, journal formats,
and the gate contract are unchanged from 0.5.x.
