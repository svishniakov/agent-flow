# Agent Flow 0.6.2

Document status: done

This bugfix release closes the remaining findings of the second independent
review. Each fix carries a regression test that fails on the unfixed code.

- **Evidence Records import never loses data.** Import completeness is checked
  per stage (record, extra fields, counters) and an interrupted import is
  completed on re-run with the same deterministic operation ids. An id that is
  already journaled is skipped only when the content matches; a content
  conflict refuses the import without touching the manual source block, and
  only fully transferred records are stripped from the manual zone.
- **Covers stay readable for journals written by 0.6.0.** Receipts without a
  document hash and receipts with empty covers no longer suppress the marker
  fallback, so pre-hash journals keep their declared section coverage. The
  0.6.1 invariant stands: receipts of superseded revisions are still ignored.
- **Strict completeness audit binds evidence to the current handoff.** The
  reviewer completeness check now passes the current document hash to the
  receipt lookup, so evidence from a superseded draft no longer satisfies it;
  the same binding was added to the QA source-bound check.
- **Release builds depend on the commit alone.** The commit export enumerates
  blobs via `git ls-tree` and reads bytes via `git cat-file`, so local Git
  attributes (such as `export-ignore` in `.git/info/attributes`) cannot change
  what lands in the plugin ZIP.
