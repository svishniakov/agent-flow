# Agent Flow 0.2.3

Document status: done

This bugfix update repairs assignment startup, preliminary review, and evidence
handling so journal bookkeeping can follow the work automatically.

- Planned assignments now bind to the actual execution mode and agent identity
  on their first source-confirmed trace. Starting a subagent no longer requires
  manually changing the planned mode; started assignments remain immutable.
- Change tasks prepare their workspace before initial verification. New
  assignments require an explicit task kind, and implementation, integration, or
  fix actions require a prepared change workspace even in compact runs.
  Read-only analysis still works without a product workspace.
- Requirements and plan QA can run before a candidate exists. Python pins the
  complete review inputs and keeps this preliminary review separate from final
  product QA. Worker readiness uses applicable check receipts and approvals;
  a later failed check blocks dependent work without another bookkeeping step.
- Readiness accepts supported MCP tool results from the QA session alongside
  native command receipts. Python preserves the exact result and its source
  binding. A fresh QA review for the same readiness duty can replace an outdated
  review while preserving history and current failure and approval checks.
  Missing configured QA produces a readiness diagnostic. Historical gate
  references use retained snapshots, and displayed attempt history cannot
  expand the QA duties allowed to authorize work.
- Architects can submit one source-confirmed `architecture-outcome` containing
  the existing brief and contract sections with an explicit decision. The writer
  creates both references to that result. Boundary proof uses its canonical
  reference without requiring a duplicate entry in lane evidence.
- Fixed ordinary worker completion and compact author-proof handling. Actual
  source completion, reported outcomes, and authorship checks remain enforced;
  final QA and reviewer acceptance still refer to the current retained product.
- Lawful updates to reviewed journal inputs now automatically preserve the
  previous bytes and their original proof binding. Historical decisions remain
  verifiable, while changes to the current task scope or plan still require an
  applicable review. Missing or malformed proof produces a diagnostic instead
  of an unhandled exception.
- Reviews now accept explicitly declared context files outside the product source
  root, including regular files listed in declared directory manifests. Current
  checks detect changes to these inputs or their declared set. Undeclared paths
  and paths through symlinks are rejected.
- Instructions now distinguish preliminary and product review and state the
  closed status vocabulary and string input requirements. The existing Python
  writer continues to generate journal formatting, hashes, and projections.
- Timed-out assignments can now be recorded directly: the writer accepts
  `stage timed-out` with `status timed-out`, and the run reference documents the
  call. The obligation stays open until a replacement lane is accepted.
- Session evidence targets the Codex desktop app structure only. Instructions no
  longer promise CLI session compatibility, and the follow-up acceptance
  scenarios run both compact and full tasks in the desktop app.
- Documentation consistency repairs: SKILL.md describes boundary `version=2`
  artifacts, Definition of Done follows the latest-contribution authorship
  model, all agent-facing commands use `"$AF_PACKAGE/scripts/..."` paths,
  `resume_phrase` is documented as a closed constant artifact field rather than
  a password, and the handoff-state reference distinguishes caller statuses
  accepted by the CLI from the stored domain values.

Existing two-document architecture results and legacy review records remain
readable. Exact retries retain their original receipts; published history and
started identities are preserved. Historical captures do not replace current
product evidence, author proofs, or independent QA and review.
