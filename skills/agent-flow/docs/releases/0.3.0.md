# Agent Flow 0.3.0

Document status: done

This release moves Agent Flow to a single current journal format and a single
source for shared rules. It is a breaking change for old runs.

- **Breaking: pre-0.3 journals are archival.** Runs created by Agent Flow 0.1.x
  (flat files) and 0.2.x (storage versions 1-2) are no longer read, validated,
  or convertible. The import, upgrade, and legacy-classification commands are
  removed. After updating, start a new run for in-flight work. Any tool that
  meets an old journal reports one clear message at the first touch:
  "unsupported journal storage version: pre-0.3 journals are archival; start a
  new run" — instead of failures surfacing mid-procedure.
- **One storage format.** New journals record storage version 3 together with
  the creating package version. `validate-run.py` prints a non-fatal warning
  when a journal was created by a different package version, so mixed-version
  projects are visible immediately.
- **Current proof formats only.** Boundary evidence requires artifact version
  2 and result hashing requires version 5; the historical v1-v4 readers and
  their weakened legacy path are deleted rather than maintained.
- **Single source for shared rules.** The stage/status event rules and the
  handoff caller-to-domain status mapping now exist exactly once, in
  `journal_structure.py`; the journal writer, handoff recorder, and run
  validator import them instead of keeping copies that can drift.
- **Consistency guard in CI.** The new `validate-rule-consistency.py` check
  fails the build if a rule table gains a second definition or if agent-facing
  documents reintroduce superseded rules, wrong script paths, or removed
  commands.
- **Release publishing hardened.** The Codex plugin publisher retries draft
  release listing visibility after creation instead of failing on a transient
  GitHub read.

Live recovery keeps working within the current format: reopen after a negative
closure, obligation resolution, operation-ID replay, and lifecycle archives are
unchanged.
