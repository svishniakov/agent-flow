# Agent Flow 0.4.1

Document status: done

This release unifies the gate vocabulary: 15 overlapping gate names collapse
into 7 contours. It is documentation and diagnostic wording only — no validator
check, artifact, or journal format changed.

- **Seven contours.** Architecture Gate (contract, design mode, capability
  routing, context propagation, execution control, approval), Simplicity Gate
  (engineering simplicity and scope coverage), Lane Boundary Gate, Contract
  Evidence Gate (claim evidence, acceptance traceability, surface evidence,
  negative fixtures — `claim-evidence.json` and `acceptance-traceability.json`
  both stay), Verification Readiness Gate (unchanged runtime state machine),
  Risk Lifecycle Gate (mitigation, resolution, blocked-resolution recovery),
  and Flow Integrity Gate (delegation trace, handoff state projection,
  mandatory independent QA review, continuation). Harness Evaluation Loop
  remains a separate loop outside the seven.
- **Old names stay readable once.** Each document mentions the retired names a
  single time in a «входит в» note at the first contour mention, so readers of
  pre-0.4.1 journals and documents can map old evidence to the new vocabulary.
- **Checkpoints documented.** `spawned`, `--prepare-conclusion`, and the
  binding `handoff` record are three checkpoints with distinct time semantics
  (admission before dispatch, writer conclusion inside the subagent, source
  binding after the turn) — not redundant calls.
- **Diagnostic wording.** Validator messages now name the contour or the
  mechanism instead of retired gate names (for example, `missing
  handoff_state`, `for Risk Lifecycle Gate`, `for Flow Integrity Gate`); one
  golden fixture expectation and one lane-test expectation were updated in
  lockstep. Harness trigger ids in `harness-evaluation.json` are data and are
  unchanged.
- **Consistency guard extended.** `validate-rule-consistency.py` now rejects
  retired gate names in agent-facing documents outside «входит в» notes, so
  the old vocabulary cannot drift back.
- **Traceable Runs reorganized.** Gate sections are grouped under contour
  headings; repeated rule statements collapse into single formulations with
  links.

No validator check was weakened or removed; golden traces stay green.
