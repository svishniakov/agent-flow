# Agent Flow 0.5.1

Document status: done

This release turns Evidence Records — the project-memory learning stream — into
journal facts with a generated view, replacing hand-edited markdown counters.

- **Evidence Records are journal operations.** New record kinds:
  `journal.py record --kind evidence-record` (`id`, `record_type`,
  `problem_class`, `context`, `outcome`, `evidence`, `reuse_when`,
  `do_not_reuse_when`, `follow_up`; optional `section`, `keywords`,
  `provenance`, `verification`, `active`) and `--kind evidence-record-outcome`
  (`counter`: `helpful`, `harmful`, or `neutral`, plus `evidence` and optional
  `active`). Records are upserted by id into the writer-owned
  `artifacts/memory/evidence-records.json`; the writer validates a full
  render/parse round-trip on every write.
- **Derived counters, no races.** Helpful/Harmful/Neutral counters are computed
  from the outcome event chain instead of stored numbers, and `Active` comes
  from the latest outcome `active` flag — manual increments are gone, together
  with their race conditions.
- **Generated notes section, preserved manual zone.** The `## Evidence
  Records` section of `.agent-work/tasks/implementation-notes.md` is rendered
  inside per-run marked blocks (`<!-- agent-flow:<run_uuid>:begin/end -->`).
  Bytes outside the blocks stay untouched as a manual zone for records not yet
  moved into the journal, and record ids duplicating the manual zone are
  rejected. The analyzer (`analyze-evidence-records.py`) is unchanged and reads
  the generated markdown exactly as before.
- **One-time import.** `journal.py import-evidence-records --run-dir <run>
  [--notes <path>]` moves existing manual entries into the journal: each record
  is written with `import:<date>` provenance (plus the original one), stored
  counters convert to outcome events, and imported entries are removed from the
  manual zone. The import is idempotent; re-running it skips existing ids.
- **Journal-based promotion.** `promote-harness-evaluation.py` now promotes
  harness findings by writing `evidence-record` journal entries instead of
  editing markdown; the `--notes` target flag is removed (the projection target
  is writer-owned) and `--dry-run` is preserved. Promotion also works on
  completed runs through the memory lifecycle.

No validator gate was weakened: Evidence Records stay advisory learning input,
and reuse still requires analyzer classification plus fresh verification.
