# Agent Flow 0.2.1

Document status: done

This bugfix release simplifies journal handling and fixes installed-package and
worker-completion failures while preserving existing journal reading.

- Retained workspaces no longer depend on filesystem device and inode identifiers
  for their entire lifetime. Content, scope, provenance, and current result checks
  remain enforced; descriptor checks still protect individual filesystem operations.
- Product acceptance is separate from audit presentation. Missing or inconsistent
  product evidence still blocks acceptance; an audit formatting finding is reported
  separately. Explicit local delivery scope can retain an unresolved external
  follow-up without declaring that external workflow complete.
- One Python writer owns journal records and projections, with fixed status and
  field types. Semantic text is rendered literally, including text that resembles
  Markdown instructions or journal markers. Historical journal reading is retained;
  published history is not rewritten.
- Both distribution archives now include the missing journal and workspace modules.
  Installed-package checks exercise imports and disposable run startup. Archive
  regression tests also exercise journal record/read and workspace preparation with
  a context root, including rejection of incomplete archives whose checksums agree.
- JSON arguments are parsed before being treated as file paths. Malformed JSON,
  wrong types, and invalid domain values are rejected before journal writes; file
  inputs remain supported.
- Ordinary workers can finish with a plain-text response. Source completion can
  enrich an existing handoff once while preserving its reported status, evidence,
  and history. Exact retries are accepted; changed or conflicting source evidence
  is rejected. QA and reviewer completion still requires strict structured evidence
  and independent acceptance of the current result.
- Removed the stale checklist that required old ceremony phrases in source files
  and instructions. Behavioral suites and checks against known retired blocking
  rules remain in place.
- Fixed resolution of inherited subagent session metadata and acceptance of analysis
  tasks before workspace preparation. Role defaults were updated to GPT-6.1 Sol.

The source test suite and frozen model-evaluation harness retain their Codex
`0.144.1` pin and `gpt-5.6-*` evaluation catalog. Installation instructions explain
how to select an application's bundled CLI explicitly through `PATH`, without
updating the global CLI. Local version, help, and bundled-catalog checks do not
prove account access or successful execution at an external model provider.

See the [installation instructions](../en/installation.md) for package validation
and CLI selection.
