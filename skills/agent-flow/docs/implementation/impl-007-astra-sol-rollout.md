# Миграция Agent Flow на Astra/Sol

Статус: модельная часть сохранена; расширение workflow отменено решением пользователя 2026-09-09.

## Действующее решение

Agent Flow сохраняет workflow версии `3d95caf`. Главный агент работает на `gpt-6-astra/high`, 26 штатных ролей используют `gpt-6-astra`, reviewer — `gpt-5.6-sol`.

Внутри одной роли точная модель не меняется при эскалации или повторной попытке. Поля `model` и `escalation_model` совпадают. Выбор reasoning использует прежние triggers и механизм resolver. Documenter и qa-verifier сохраняют согласованные `high → xhigh`; остальные уровни соответствуют прежней версии.

Промпты адаптированы к моделям в существующих файлах ролей и передаются штатным генератором конфигураций. Маршруты, делегирование, попытки исправления, проверки качества и обычные рабочие журналы остаются прежними.

## Отменённая часть impl-007

Удалены обязательный `model-settings.json`, его валидатор, специальные генераторы доказательств и требования захвата `thread/start`, `turn/start` и системного завершения текущего хода. Отменены добавленные правила управления сессиями и подтверждения каждого вызова по внутренним журналам Codex. Нового журнала взамен нет.

Первоначальная редакция документа и результаты миграции доступны в истории Git, коммит `4a572b7`. Они не задают требования действующему workflow.

Проверяются прежние положительные и отрицательные сценарии, конфигурации всех 27 ролей, запрет подмены модели и обычное выполнение нейтральной задачи из Codex Desktop и CLI. Проверка фреймворка не зависит от конкретного продукта.
